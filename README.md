# 🏠 VR Interactive Room Walkthrough

An immersive **Virtual Reality (VR) room exploration project** that lets users experience and navigate a virtual indoor environment through a browser-based 3D experience.

Built using modern web technologies, the project demonstrates how interactive 3D environments can create engaging virtual walkthroughs without requiring a traditional desktop application. Works on both androids and desktop.

## 🌐 Live Demo

**[Explore the Virtual Room](https://sajil-nair.github.io/AR-ROOM-VIEW/)**

## ✨ Features

- 🏠 **3D Virtual Environment** — Explore a digitally created room.
- 🎮 **Interactive Walkthrough** — Navigate and experience the virtual space.
- 🥽 **Immersive Experience** — Explore the potential of VR and WebXR technologies.
- 🌐 **Browser-Based Access** — Experience the project through a web browser.
- 🎨 **3D Scene Rendering** — Real-time rendering of the virtual environment.

## 🛠️ Tech Stack

- **HTML5** — Web page structure
- **CSS3** — Styling and layout
- **JavaScript** — Interaction and application logic
- **Three.js** — 3D rendering and scene management
- **WebGL** — Real-time graphics rendering
- **WebXR** — Web-based immersive experience capabilities

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/SAJIL-NAIR/AR-ROOM-VIEW.git
```

### 2. Open the project

```bash
cd AR-ROOM-VIEW
```

### 3. Run locally

Open the project using a local development server, such as the **Live Server** extension in Visual Studio Code....

Alternatively, explore the deployed version:

**[Launch VR Room View](https://sajil-nair.github.io/AR-ROOM-VIEW/)**

## 🎯 Project Objective

To demonstrate the use of real-time 3D rendering and interactive web technologies in creating an immersive virtual indoor environment that users can explore digitally.
